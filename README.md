## Selected Work

### CustodyIQ

**Role: Technical & Product Lead**

CustodyIQ is freight technology focused on evaluating whether independent transportation systems tell the same operational story and preserving source evidence for review when those systems disagree.

My work spans product architecture, cloud deployment, API and transportation-system integration, validation design, governance, operational workflows, and technical quality assurance. Current platform work uses a Python/FastAPI/PostgreSQL architecture with Auth0 and Azure infrastructure, while freight-lab validation spans independent TMS, WMS, ERP, and telematics systems.
